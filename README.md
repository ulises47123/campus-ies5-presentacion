# Campus Virtual IES N° 5 — Aplicación de escritorio

Página informativa del proyecto de **Prácticas Profesionalizantes III** de la
Tecnicatura Superior en Soporte de Infraestructura de Tecnología de la Información,
Instituto de Educación Superior N° 5 "José Eugenio Tello" (San Salvador de Jujuy, 2026).

👉 Ver la página: https://ulises47123.github.io/campus-ies5-presentacion/

## De qué se trata
Un programa para Windows que reúne en una sola ventana las materias, clases, tareas,
calificaciones, mensajes y novedades del Campus Virtual del IES N° 5. Entra al campus
con el usuario del estudiante, recorre sus aulas y le muestra todo resumido y ordenado.

## Contenido del repositorio
- `index.html` — página que explica el proyecto, con el botón para completar el formulario.
- `formulario.html` — formulario (en preparación; todavía no envía respuestas).
- `estilos.css` — estilos compartidos.
- `escudo_ies5.png` — escudo de la institución.
